Updated Goal & Questions¶

The goal of this project is to analyze different data points across games on the publishing platform, Steam, and make connections between what makes them popular, player demographics, and common denominators between games that win awards (among other things).

This project will likely feature us asking multiple smaller questions rather than a single larger one, with the overarching goal of examining trends that exist across different metrics, and figuring out if there are ways to predict breakout games based on imperical data.

These questions include:

  • Investigating trends between Steam games that win specific awards, such as Game of the Year, and more.
  • Game pricing and popularity across genres, themes, publishers, etc.
  • **More as we explore the data*

Questions will be added/updated as our research continues!

  • Kaggle Steam Games Dataset

''' Created a function to get the main genre (first index of genre as categorized by Steam) for each game. For the purposes of our research, we will
not count "Indie" as a game genre, but as a way to categorize the production of certain games (Indie, AA, AAA, etc.)
Therefore, if a game's main genre is Indie, we skip over it and use the next genre in the list.'''

def get_main_genre(game):
  if game is nan:
    return

  genres = game.split(',')

  if (str(genres[0]).upper == "INDIE") & (len(genres) > 1): # Some Indie observations will make it into the genre list if it is their only genre listed
    main_g = genres[1]
  else:
    main_g = genres[0]

  return str.strip(main_g) # Returns the genre, stripped of spaces in the front and back of the string

# apply the function to create the new column "main genre"
games_paid['main genre'] = games_paid['genres'].apply(get_main_genre)
genre_list = games_paid['main genre'].unique() # Lists all the genres gathered form the dataset

''' Since the owner column is a string of a range, we'll have to split it
and convert them to ints. Once we get the raw numbers, we can add and divide
them to get an average that we will use as an owner estimation'''

def get_owners_est(x):
  vals = x.split("..")
  lower = int(vals[0].replace(",", "").strip()) # get rid of the commas in the numbers and strip any spaces
  higher = int(vals[1].replace(",", "").strip())
  return (lower + higher) / 2


# Create a new column that has the int owner estimations of each game
joined["owner est"] = joined['owners'].apply(get_owners_est)
owner_info = joined[["appID", "name", "owners", "owner est"]]


joined2 = pd.merge(owner_info, games_paid, on = ["appID", "name"])
joined2["revenue est"] = joined2['price'].astype(float) * joined2['owner est']

# Finally, we can extract the relevant columns for the data we will be using in our models

Model 1: Revenue Prediction Model¶

  • Can we predict a game's estimated revenue based on its genre, price, and metacritic score?
  • Features: Main genre, price, metacriticScore
  • Dependent variable: Revenue est
  • Method: Multiple Linear Regression
  • Why: The data points (EDA) shows variation in revenue across different genres and price ranges, which implies these features may be able to be predicted.

Model 2: Genre Classification Model¶

  • Can we predict a game's main genre based on its price and metacritic score?
  • Features: Price, metacriticScore, owner est
  • Dependent variable: Main genre
  • Method: K-Nearest Neighbors
  • Why: The EDA data shows distinct clustering patterns between genres in terms of pricing and scores, which could make building a classification model plausible.
